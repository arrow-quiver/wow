Get set up in a minute

The app does the fiddly bits for you, including the addon.

  1. Download and run the installer. If Windows SmartScreen pops up, click More info → Run anyway.
  2. Open Guild Camp. It finds your WoW folder and installs the guild addon for you.
  3. Log in to WoW and play. Guild info shares in game through the addon. Type /reload if the app's waiting for fresh data.

The app and addon keep themselves up to date.
